# Materia Redes Neuronales - Trabajos Prácticos

Esta carpeta reúne dos trabajos prácticos realizados para la materia Redes Neuronales. Los notebooks contienen las implementaciones y experimentos, mientras que los PDFs incluyen los informes científicos completos.

## Práctico 1 - Simulación del modelo de Izhikevich

[Notebook](TP1/TP1_RN.ipynb) | [Informe científico (PDF)](TP1/TP1_RN.pdf)

Este trabajo implementa e integra numéricamente el modelo de neuronas de Izhikevich mediante el método RK4 con un paso de 0,1 ms. Se reproducen distintos patrones corticales de disparo y se analiza cómo influyen los parámetros del modelo y la corriente externa en el potencial de membrana y el comportamiento de la neurona.

## Práctico 2 - Clasificación de Fashion-MNIST

[Notebook](TP2/TP2_RN.ipynb) | [Informe científico (PDF)](TP2/TP2_RN.pdf)

Este trabajo entrena y evalúa una red neuronal totalmente conectada para clasificar imágenes de Fashion-MNIST. Compara los optimizadores SGD y Adam con varias semillas, analiza las curvas de entrenamiento y validación, y evalúa el modelo seleccionado sobre el conjunto de test mediante pérdida, accuracy y una matriz de confusión normalizada.

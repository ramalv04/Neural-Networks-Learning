# Neural Networks Course - Practical Assignments

This folder contains two practical assignments developed for the Neural Networks course. The notebooks include the implementations and experiments, while the PDFs contain the complete scientific reports.

## Practical 1 - Izhikevich Neuron Simulation

[Notebook](TP1/TP1_RN.ipynb) | [Scientific report (PDF)](TP1/TP1_RN.pdf)

This assignment implements and numerically integrates the Izhikevich neuron model with the fourth-order Runge-Kutta method (RK4), using a 0.1 ms step. It reproduces several cortical spiking patterns and analyzes the effect of the model parameters and the external current on membrane potential and firing behavior.

## Practical 2 - Fashion-MNIST Classification

[Notebook](TP2/TP2_RN.ipynb) | [Scientific report (PDF)](TP2/TP2_RN.pdf)

This assignment trains and evaluates a fully connected neural network to classify images from Fashion-MNIST. It compares SGD and Adam across multiple seeds, studies training and validation curves, and evaluates the selected model on the test set using loss, accuracy, and a normalized confusion matrix.
